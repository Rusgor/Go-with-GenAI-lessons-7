# Етап 7 — GORM моделі та репозиторії

## Мета
Додати окремий persistence layer LibraTrack з контекстом у кожному запиті, зберігши поточні моделі й memory store пристроїв.

## Виконано
- Додано моделі `Book`, `Author`, `Category`, `Copy`, `User`; `Book` має GORM-зв’язки категорії та авторів через `book_authors`.
- Додано підключення до PostgreSQL із пулом (25 максимальних / 5 idle з’єднань), контекстним Ping і `logger.Info` для SQL.
- Додано `BookRepository` CRUD/List, репозиторії авторів, категорій і копій, переклад помилок БД та міграційний helper `ApplyMigrations`.
- У кожному репозиторному запиті використовується `WithContext(ctx)`; `List` завантажує `Authors` і `Category` через `Preload`.
- Додано інтеграційні тести для зв’язків, CRUD, обробки невідомого автора, сталої кількості SELECT та обліку доступних копій.

## Перевірки
- `go test ./...`, `go test -race ./...`, `go vet ./...` і `go build ./...` успішні без налаштованого DB URL.
- Інтеграційні тести для PostgreSQL позначаються пропущеними, якщо `TEST_DATABASE_URL` не задано. У цьому середовищі змінну навмисно залишено порожньою, тому реальні DB тести не виконувалися.

## Статус
Код та unit-тести готові; інтеграційна перевірка має бути повторена з `TEST_DATABASE_URL` на ізольованій тестовій базі.
