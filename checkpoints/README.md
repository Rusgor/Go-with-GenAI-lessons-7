# Контрольні точки виконання ДЗ

У цій папці зберігаються окремі звіти про кожен етап реалізації REST API. Після завершення етапу його звіт додається тут, а цей файл оновлюється зі статусом і посиланням на звіт.

| Етап | Статус | Звіт |
|---|---|---|
| 1. Каркас, health, створення й отримання пристрою | Виконано | [Звіт етапу 1](stage-01.md) |
| 2. Валідація та формат помилок | Виконано | [Звіт етапу 2](stage-02.md) |
| 3. PUT, DELETE, ідентифікатори й час | Виконано | [Звіт етапу 3](stage-03.md) |
| 4. Список, сортування, пагінація та фільтр | Виконано | [Звіт етапу 4](stage-04.md) |
| 5. CORS і конкурентність | Виконано | [Звіт етапу 5](stage-05.md) |

Кожен звіт описує мету етапу, внесені зміни, перевірки та результат. Тестові файли й файли CI не змінюються.
