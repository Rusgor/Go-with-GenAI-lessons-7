# Звіт-контрольна точка: етап 1

**Тема:** каркас API, перевірка стану, створення та отримання пристрою  
**Варіант:** `devices`  
**Статус:** виконано  
**Дата:** 2026-10-06

## Мета

Реалізувати мінімальний набір REST API, визначений першим етапом у [README.md](../README.md): `GET /health`, створення ресурсу `POST /api/v1/devices` і отримання ресурсу `GET /api/v1/devices/{id}`.

Для варіанта `devices` обов’язкові рядкові поля: `name`, `serial`, `manufacturer`, `type`. Необов’язкові поля: ціле `warranty_months` і текстове `comment`.

## Що реалізовано

- Додано модель пристрою та тип запиту створення в [internal/model/device.go](../internal/model/device.go).
- Додано потокобезпечне сховище в пам’яті в [internal/repository/memory.go](../internal/repository/memory.go). ID починаються з `1`; кожен екземпляр роутера має власне сховище. При створенні проставляються `created_at` і `updated_at` у UTC.
- Додано HTTP-обробники в [internal/handler/device.go](../internal/handler/device.go): `GET /health`, `POST /api/v1/devices` і `GET /api/v1/devices/{id}`.
- Підключено роутер і залежності в [internal/app/app.go](../internal/app/app.go).
- Необов’язкові поля серіалізуються завжди: передане значення повертається клієнту, незадане кодується як `null`.
- Невідомі маршрути повертають `404`.

## Перевірка

Початкова команда `go test ./...` була запущена до реалізації. Тести тоді очікувано не пройшли, оскільки заглушка `NewRouter()` повертала `501 Not Implemented`.

Після реалізації та форматування виконано:

```text
go test ./internal/app -run TestStage1 -v
```

**Результат:** усі 7 тестів `TestStage1_*` пройшли. Перевірені health endpoint, невідомий маршрут, створення, необов’язкові поля, отримання за ID та ізоляція сховищ різних роутерів.

Повний набір `go test ./...` після цього етапу ще не запускався. Валідація, формат помилок та поведінка наступних етапів залишаються невиконаними.

## Пояснення ключових рішень

- Вказівники для необов’язкових значень дають змогу відрізнити незадане поле від нульового значення й повернути `null` у JSON.
- Сховище створюється всередині `NewRouter()`, тому різні екземпляри API не ділять стан.
- М’ютекс захищає map від одночасного доступу; копіювання значень не відкриває зовнішньому коду змінювані поля сховища.
- `time.Time` автоматично серіалізується в JSON у форматі RFC 3339.
